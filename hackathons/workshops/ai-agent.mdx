Plan a workshop where participants build an AI agent that pays on BOT Chain testnet from a vault with a daily limit and asks a human before larger payments.

This workshop depends on the [AI agent template](/templates/ai-agent/index), which is in development. The outline below is a draft. You can run a version today with the [AI agent guides](/guides/ai-agents/overview), which were tested on testnet.

## What participants will build

An agent that:

1. Takes a request in plain language, such as "pay 2 USDT to this address".
2. Calls a payment tool that sends testnet USDT from an agent vault.
3. Is stopped by the vault's daily spending limit, enforced on-chain.
4. Asks a human to approve anything above a threshold.

## Draft outline

Timings are suggestions for a 90-minute session.

## Prerequisites

- The [setup workshop](/hackathons/workshops/setup) and [first contract workshop](/hackathons/workshops/first-contract), or equivalent experience.
- Node.js LTS.
- An API key for an LLM provider. Organizers should decide before the event whether they provide keys or participants bring their own, and never share one key in a public channel.
- Testnet USDT, from a swap on [BDEX V2](/guides/defi/swaps/bdex-v2).
