`botChain` is the viem chain object for BOT Chain mainnet. Pass it to any viem client or wagmi config to work with chain 677.

<EarlyRelease />

<Warning>
  **Mainnet uses real BOT.** Build and test against [`botChainTestnet`](/sdk/chains/bot-chain-testnet) first, and only switch to `botChain` when you're ready to spend real funds.
</Warning>

## Import

```ts Import
import { botChain } from "@uzolabs/sdk/chains";
```

    <ResponseField name="apiUrl" type="string">`"https://scan.botchain.ai/api/v2"`. BOTScan's v2 API, used by the [explorer client](/sdk/explorer/overview).</ResponseField>

<ResponseField name="contracts.multicall3.address" type="Address">
  `0x47FA21f684bBAD707A53a0f9BE59F1422F46C265`. viem uses it for `multicall` and for automatic request batching.
</ResponseField>

`botChain` has no `testnet` field. viem treats a missing value as mainnet.

## Example

```ts mainnet-read.ts
import { createPublicClient, formatEther, http } from "viem";
import { botChain } from "@uzolabs/sdk/chains";

const client = createPublicClient({ chain: botChain, transport: http() });
const [blockNumber, gasPrice] = await Promise.all([client.getBlockNumber(), client.getGasPrice()]);
console.log(`Block ${blockNumber}, gas price ${formatEther(gasPrice, "gwei")} gwei`);
console.log(`${botChain.blockExplorers.default.url}/block/${blockNumber}`);
```

Output from a run on 2026-10-02:

```text Output
Block 25326924, gas price 20 gwei
https://scan.botchain.ai/block/25326924
```

This only reads from the chain. It doesn't send a transaction or use a wallet.
