`botChainTestnet` is the viem chain object for BOT Chain testnet. Pass it to any viem client or wagmi config to build and test on chain 968 with free tBOT.

<EarlyRelease />

<TestnetOnly />

## Import

```ts Import
import { botChainTestnet } from "@uzolabs/sdk/chains";
```

## Fields

<ResponseField name="id" type="968">
  The chain ID.
</ResponseField>

<ResponseField name="name" type="string">
  `"BOT Chain Testnet"`.
</ResponseField>

<ResponseField name="nativeCurrency" type="object">
  <Expandable title="properties">
    <ResponseField name="name" type="string">`"tBOT"`</ResponseField>
    <ResponseField name="symbol" type="string">`"tBOT"`</ResponseField>
    <ResponseField name="decimals" type="18">tBOT uses 18 decimals.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="rpcUrls.default.http" type="string[]">
  `["https://rpc.bohr.life"]`. The public testnet RPC. It's sometimes slow or briefly unavailable, so retry failed reads.
</ResponseField>

<ResponseField name="blockExplorers.default" type="object">
  <Expandable title="properties">
    <ResponseField name="name" type="string">`"BOTScan"`</ResponseField>
    <ResponseField name="url" type="string">`"https://scan.bohr.life"`</ResponseField>
    <ResponseField name="apiUrl" type="string">`"https://scan.bohr.life/api/v2"`</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="contracts.multicall3.address" type="Address">
  `0x47FA21f684bBAD707A53a0f9BE59F1422F46C265`, the same as mainnet. The standard `0xcA11...CA11` address has no code on testnet, so this field matters.
</ResponseField>

<ResponseField name="testnet" type="true">
  Marks the chain as a testnet. Libraries that read viem chain objects can use it to tell test networks apart.
</ResponseField>

## Example

```ts testnet-balance.ts
import { createPublicClient, formatEther, http } from "viem";
import { botChainTestnet } from "@uzolabs/sdk/chains";

const client = createPublicClient({ chain: botChainTestnet, transport: http() });
const address = "0xEc526474F4F9De027942d5f7118A9613266B0C4c"; // Replace with your address
const balance = await client.getBalance({ address });
console.log(`${formatEther(balance)} ${botChainTestnet.nativeCurrency.symbol}`);
console.log(`${botChainTestnet.blockExplorers.default.url}/address/${address}`);
```
