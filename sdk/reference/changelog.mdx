This page lists what changed in each `@uzolabs/sdk` release, so you can see what's safe to upgrade to and what to change in your code.

<EarlyRelease />

The SDK follows semantic versioning. Before 1.0, a minor release (0.x.0) can include breaking changes, so pin an exact version and read this page before you upgrade. The source of truth is [CHANGELOG.md on GitHub](https://github.com/uzolabs/uzo-sdk/blob/main/CHANGELOG.md). Releases are published to [npm](https://www.npmjs.com/package/@uzolabs/sdk).

<Update label="0.2.0" description="2026-09-30">
  **Added**

  - [`@uzolabs/sdk/contracts`](/sdk/contracts/overview): the `addresses` object, [`getAddresses(chainId)`](/sdk/contracts/addresses), [`USDT_RESOURCE_ID`, `TOKENS` and `EXTERNAL_BRIDGE`](/sdk/contracts/constants) (experimental), and [typed ABIs](/sdk/contracts/abis) generated from BOTScan, plus viem's `erc20Abi`.
  - [`@uzolabs/sdk/explorer`](/sdk/explorer/overview): `createExplorerClient({ chainId })` with `getAddressInfo` and `getContract`. No API key needed.
  - [Errors](/sdk/reference/errors): `UzoError` and its subclasses, each with a stable `code`.

  **Removed**

  - The mainnet `bdexV3SwapRouter02` address entry. BOTScan verifies that address as a `UniversalRouter`, not a SwapRouter02, and the mainnet Universal Router isn't confirmed yet.
</Update>

<Update label="0.1.0" description="2026-09-30">
  **Added**

  - First release. [`@uzolabs/sdk/chains`](/sdk/chains/overview) with viem chain definitions for [BOT Chain](/sdk/chains/bot-chain) (`botChain`, chain ID 677) and [BOT Chain Testnet](/sdk/chains/bot-chain-testnet) (`botChainTestnet`, chain ID 968), including the RPC, BOTScan explorer and Multicall3 settings.
</Update>
