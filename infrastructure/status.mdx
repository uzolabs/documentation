Check which Uzo products and BOT Chain services you can use today, which are in development and which are planned.

Last checked: 2026-10-03.

## What the statuses mean

| Status | Meaning |
| --- | --- |
| **Live** | Running now. You can use it today. |
| **Early release** | Published and usable. The API may change before 1.0. |
| **Ready** | Published template, deployed and verified on testnet. Not audited. |
| **In development** | Being built. Docs describe the planned design and may change. |
| **Planned** | Not started or not public. Docs explain the idea and what to use meanwhile. |
