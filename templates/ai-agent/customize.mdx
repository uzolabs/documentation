<TemplateInDevelopment />

## Why there's nothing to customize yet

The AI agent template is in development. This page will list its settings once it's published. The choices below apply to any agent you build from the guides now.

## Do it today

- **Set the daily limit.** Pick the most you'd accept losing in one day if the agent's key leaked or the model misbehaved. See [Spending limits](/guides/ai-agents/spending-limits).
- **Choose recipients and tokens.** Allow only the addresses and tokens the agent needs. See [Agent vaults](/guides/ai-agents/agent-vaults).
- **Set the approval threshold.** Decide which actions a person must approve. See [Human approval](/guides/ai-agents/human-approval).
- **Add or remove tools.** Every tool you add is something the model can try. Give each one a narrow schema and simulate before sending. See [Tool calling](/guides/ai-agents/tool-calling).
- **Check trust.** If you rely on an identity or reputation contract, plug it in through a small interface. See [Identity hooks](/guides/ai-agents/identity-hooks).

<Warning>
On mainnet an agent spends real funds. Use a separate owner and operator, keep the daily limit small, and complete the [security checklist](/guides/ai-agents/security-checklist) first.
</Warning>
