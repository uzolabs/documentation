## Add to your app

These objects work with `wallet_addEthereumChain` (EIP-3085) in a browser wallet:

<CodeGroup>
```json Testnet
{
  "chainId": "0x3c8",
  "chainName": "BOT Chain Testnet",
  "nativeCurrency": { "name": "BOT", "symbol": "tBOT", "decimals": 18 },
  "rpcUrls": ["https://rpc.bohr.life"],
  "blockExplorerUrls": ["https://scan.bohr.life"]
}
```

```json Mainnet
{
  "chainId": "0x2a5",
  "chainName": "BOT Chain",
  "nativeCurrency": { "name": "BOT", "symbol": "BOT", "decimals": 18 },
  "rpcUrls": ["https://rpc.botchain.ai"],
  "blockExplorerUrls": ["https://scan.botchain.ai"]
}
```
</CodeGroup>

For viem and wagmi, see the `defineChain` example in [Build your first dApp](/get-started/first-dapp).
