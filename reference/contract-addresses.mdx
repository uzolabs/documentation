## Check an address yourself

Ask BOTScan for the contract's name and whether its source is verified:

```bash check-address.sh
curl -s https://scan.bohr.life/api/v2/addresses/0x75edC9335175Fc0552D51D48439F229c10420fe3 \
  | grep -oE '"(is_verified|name)":("[^"]*"|true|false)'
```
