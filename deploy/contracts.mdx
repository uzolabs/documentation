## The Deployed event

Every factory emits this event for each contract it creates. See [How it works](/deploy/how-it-works#the-deployed-event) for what each field means.

```solidity Deployed event
event Deployed(address indexed deployer, address indexed instance, bytes32 indexed templateId, uint16 version);
```

## uzoTemplate values

Every contract a Uzo factory creates returns its template ID and version from `uzoTemplate()`. The ID is a short string stored as `bytes32`, and it's the same value as `templateId` in the `Deployed` event.

```solidity Template contracts
function uzoTemplate() external pure returns (bytes32 id, uint16 version);
```

| Template | Contract | `id` | `version` |
| --- | --- | --- | --- |
| Token | `UzoToken` | `uzo.token` | 1 |
| NFT Collection | `UzoNFT` | `uzo.nft` | 1 |
| Tip Jar | `UzoTipJar` | `uzo.tipjar` | 1 |

Any contract can return these values. To be sure a contract came from Uzo, check that one of the factories above emitted a `Deployed` event with it as the `instance`.
