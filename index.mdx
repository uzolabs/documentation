**BOT Chain has the pieces. Uzo is the path.**

Use these docs to go from zero to a working app on BOT Chain: set up a wallet, deploy a contract, connect a frontend and use the chain's DEX and bridge.

*Uzo* is Igbo for road, path or way. Uzo Labs builds the developer path for BOT Chain: guides, an SDK, starter templates and infrastructure. The docs are written for developers who are new to BOT Chain, including students building at their first hackathon.

## What you can use today

BOT Chain itself is live, so every guide that talks to the chain works now. The Uzo SDK has an early release, some templates are ready, and the hosted infrastructure is still planned. Pages about anything not yet available carry a status note and show you how to do the same thing by hand today. See [How Uzo fits together](/get-started/how-it-works) for the status of each piece, and the [changelog](/changelog) for what changed recently. If you meet an unfamiliar term, check the [glossary](/reference/glossary).
