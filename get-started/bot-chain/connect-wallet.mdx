Add BOT Chain to MetaMask so you can see your balance, sign transactions and use dApps on mainnet and testnet. Other EVM wallets work the same way.

## What you'll do

- Add **BOT Chain testnet** by hand (Chainlist doesn't list it correctly).
- Add **BOT Chain mainnet** through Chainlist or by hand.

## Prerequisites

- [MetaMask](https://metamask.io/download/) installed in your browser.

BOT Chain also has its own wallet, BO Wallet. See [BOT Chain's quick guide](https://dev-docs.botchain.ai/docs/Developers/quick-guide/) for details.

## Network values

<Tabs>
  <Tab title="Testnet">
    | Field | Value |
    | --- | --- |
    | Network name | `BOT Chain Testnet` |
    | RPC URL | `{{testnet-rpc}}` |
    | Chain ID | `{{testnet-chain-id}}` |
    | Currency symbol | `tBOT` |
    | Block explorer URL | `{{testnet-explorer}}` |
  </Tab>
  <Tab title="Mainnet">
    | Field | Value |
    | --- | --- |
    | Network name | `BOT Chain` |
    | RPC URL | `{{mainnet-rpc}}` |
    | Chain ID | `{{mainnet-chain-id}}` |
    | Currency symbol | `BOT` |
    | Block explorer URL | `{{mainnet-explorer}}` |
  </Tab>
</Tabs>

The faucet and BOTScan show the testnet token as `BOT`. You can use either `tBOT` or `BOT` as the symbol in your wallet; `tBOT` makes it easier to tell the networks apart.

## Add testnet by hand

<Steps>
  <Step title="Open the network settings">
    In MetaMask, open the network menu at the top left and choose **Add a custom network**.

    <Frame>
      <img src="/images/connect-wallet-add-network.png" alt="MetaMask Manage networks list with the Add a custom network button at the bottom" />
    </Frame>
  </Step>
  <Step title="Enter the testnet values">
    Fill in each field from the **Testnet** tab above, then click **Save**.

    <Frame>
      <img src="/images/connect-wallet-network-form.png" alt="MetaMask network form named BOT Chain Testnet with chain ID 968, RPC rpc.bohr.life, symbol tBOT and explorer scan.bohr.life, with MetaMask warnings suggesting the name Datagram and the symbol DGRAM" />
    </Frame>

    MetaMask shows orange warnings on this form. They're expected; see the note below.
  </Step>
  <Step title="Switch to the network">
    Choose **BOT Chain Testnet** from the network menu. Your balance shows in tBOT.
  </Step>
</Steps>

<Warning>
  Chain ID 968 is registered to a different network, Datagram, on [Chainlist](https://chainlist.org) and in the public chain registry. Don't add testnet through Chainlist.

  Because of that, MetaMask warns that the network name may not match chain 968 and suggests **Datagram**. It also warns that the currency symbol doesn't match and suggests **DGRAM**. Ignore both suggestions and keep `BOT Chain Testnet` and `tBOT`. The warnings are safe to dismiss only if the RPC URL is exactly `{{testnet-rpc}}` and the explorer is `{{testnet-explorer}}`. If either is different, stop and check the [Networks](/reference/networks) page.
</Warning>

## Add mainnet

<Tabs>
  <Tab title="With Chainlist">
    1. Open [BOT Chain Mainnet on Chainlist](https://chainlist.org/chain/677).
    2. Check that the chain ID is 677 and the explorer is `scan.botchain.ai`.
    3. Click **Connect Wallet** and approve the connection in MetaMask. The button then changes to **Add to MetaMask**. Click it and approve the request.

    <Frame>
      <img src="/images/connect-wallet-chainlist.png" alt="Chainlist page for BOT Chain Mainnet showing chain ID 677, currency BOT, explorer scan.botchain.ai and the RPC list" />
    </Frame>
  </Tab>
  <Tab title="By hand">
    Follow the same steps as testnet, using the values in the **Mainnet** tab above.
  </Tab>
</Tabs>

<Warning>
  Mainnet uses real BOT. Practise on testnet first, and never paste a seed phrase or private key into a website. See [Security](/reference/security).
</Warning>

## Verify it worked

1. Switch to **BOT Chain Testnet** in MetaMask.
2. Copy your address and open `{{testnet-explorer}}/address/YOUR_ADDRESS` in your browser.
3. The balance on BOTScan matches the balance in MetaMask.

If your balance is zero, claim tokens from the [faucet](/get-started/bot-chain/get-testnet-tokens).

## Troubleshooting

<AccordionGroup>
  <Accordion title="MetaMask says the chain ID returned by the RPC doesn't match">
    The chain ID field must match the RPC URL. Use 968 with `{{testnet-rpc}}` and 677 with `{{mainnet-rpc}}`. Check for a trailing space or a typo in the URL.
  </Accordion>
  <Accordion title="MetaMask warns that the network details don't match">
    For chain 968 this is expected, because the public registry lists a different network under that ID. Continue only if the RPC URL is exactly `{{testnet-rpc}}`.
  </Accordion>
  <Accordion title="My balance shows 0 after using the faucet">
    Check that MetaMask is on **BOT Chain Testnet**, not mainnet or another network. Then check the address on BOTScan testnet. If BOTScan also shows 0, the claim didn't go through; see [Get testnet tokens](/get-started/bot-chain/get-testnet-tokens).
  </Accordion>
</AccordionGroup>
