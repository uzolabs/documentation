# Fonts

`docs.json` loads the body font from `/fonts/Satoshi-Variable.woff2`. That file is not in the repo yet.

To add it:

1. Download Satoshi from Fontshare: https://www.fontshare.com/fonts/satoshi
2. Read the licence that comes with the download and confirm it allows self-hosting on a website.
3. Copy the variable font `Satoshi-Variable.woff2` into this folder.

Until the file is added, the site falls back to the default body font.
